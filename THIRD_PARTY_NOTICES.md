# Avisos de terceiros

O DriveAutomate usa bibliotecas de terceiros, incluindo:

- PySide6 / Qt for Python — edição comunitária sob LGPLv3/GPLv3 ou edição sob
  licença comercial da Qt, conforme o pacote/distribuição escolhido.
- google-api-python-client e google-auth-oauthlib — licença Apache-2.0.
- openpyxl — licença MIT.
- requests — licença Apache-2.0.
- PyInstaller — GPL-2.0-or-later com exceção para distribuir aplicações
  compiladas.

Os textos e termos vigentes devem ser conferidos nas versões efetivamente usadas
pela release. Consulte:

- https://doc.qt.io/qtforpython-6/licenses.html
- https://www.qt.io/licensing/open-source-lgpl-obligations
- https://github.com/googleapis/google-api-python-client
- https://foss.heptapod.net/openpyxl/openpyxl
- https://requests.readthedocs.io/en/latest/community/updates/#release-and-version-history
- https://pyinstaller.org/en/stable/license.html

Ao redistribuir o executável, mantenha estes avisos acessíveis e cumpra as
obrigações da opção de licença adotada para Qt/PySide6.

Este arquivo é um inventário técnico, não aconselhamento jurídico. Para uma
release pública, distribua-o junto ao executável e revise as obrigações da
licença efetivamente usada.
